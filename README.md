# Ricardo Horibe Portfolio

## Local development

Run npm install, then npm run dev. Required release checks are npm run format:check, npm run lint, npm run typecheck, npm run test, and npm run build.

## Content

Only add professional content that is supported by Ricardo's LinkedIn-exported resume. Do not commit the raw resume or a phone number. Keep unverified projects and contact destinations omitted or pending.

## GitHub Pages

In repository Settings > Pages, choose GitHub Actions as Source. Add ricardo.horibe.com.br as Custom domain, configure its DNS record with the DNS provider, wait for verification, then enable Enforce HTTPS. Push main to run the workflow.
